# Imagens Públicas — Sonessia

Para adicionar ou alterar a fotografia de fundo do painel direito da tela de login:
1. Coloque o arquivo de imagem no caminho: `public/images/login-background.jpg` (ou `.png` / `.webp`).
2. A tela de login verificará e carregará automaticamente a imagem informada na propriedade CSS de fundo com sobreposição suave de gradiente roxo.
3. Se nenhuma imagem for adicionada, o painel exibirá o gradiente elegante em tons de roxo `#24113D` com arte vetorial de ondas sonoras harmoniosas.
